# 🚀 Project: Complex NASA API

### Goal: Use NASA's API to return all of their facility locations (~400). Display the name of the facility, its location, and the weather at the facility currently. 

### Features: 
Ever wanted to know the locations of ALL of NASA's facilities? Click the button and find the closest facilty near you! 

View all ~400 NASA facilities and the weather at each location. This app uses the [NASA facilities API](https://data.nasa.gov/dataset/nasa-facilities-api/resource/8da12948-3793-4ec1-b5c6-f95e86fd6021) to print all facilities to the DOM. It also uses a [weather api](https://www.weatherapi.com/docs/) to print the weather for each respective facility.

- Click the link in the about section of this repo to the right or simply [CLICK HERE](https://priscilla-ruilova.github.io/Complex-NASA-api/)
